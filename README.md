# 蓝航Lite

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/Micheal-Reber/lanhang-lite)](https://github.com/Micheal-Reber/lanhang-lite/releases)
[![Android](https://img.shields.io/badge/Android-8.0%2B-green)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.3.21-purple)](https://kotlinlang.org)

南昌航空大学「蓝航」App 的第三方轻量客户端，包名 `com.lanhang.lite`，纯原生 Android（Kotlin + Material 3）。

官方 App 里大部分页面都是联网加载的 H5，每次打开都要转圈等一会儿。这个项目只把每天真正会看的那几件事 —— 课表、成绩、工作圈、办事大厅、成员录、图书馆座位 —— 做成本地原生界面：能用缓存就不联网，能一次点完就不点三次。

> **免责声明：本项目与南昌航空大学及官方「蓝航」App 没有任何关系，非官方、未获授权。**
>
> - 所有接口协议来自对公开客户端的抓包与逆向分析，仅供**个人学习交流**使用，请勿用于商业用途。
> - 使用本客户端产生的任何后果（接口异常、数据不一致、账号受限等）由使用者自行承担。
> - 如校方或权利方提出要求，本项目将立即停止分发。

> **本仓库不含网络层。** 学校侧接口地址、校园网认证协议实现与会话/密钥位于未公开的 `:engine` 模块，**克隆后无法直接构建**（这是刻意的）。只读代码不受影响，想跑起来请见 [先决条件：闭源模块](#先决条件闭源模块engine)。

## 功能

### 课表

- 两种视图，右上角一键切换：**网格视图**（七列 × 12 节的时间表，含午休 / 晚休色带，一眼看清哪节有空）与**列表视图**（整周 7 天摘要 + 每天课程区，纵向滚动，适合只看「今天有什么」）
- 左右滑动翻周：页面跟手平移，松手按「拖过的距离 + 手上的速度」判定吸附（随手一划就翻），学期首末周有阻尼回弹；换周后保持原来的纵向位置
- 今天的整列铺淡蓝底，第一眼就能定位到当天；周次可点开选择任意周
- 按周缓存：进页面先显示本地缓存、**不联网**，只有下拉刷新才覆盖；切到没缓存的周才按周补拉
- 课程配色按课名哈希生成（同一门课永远是同一个色，不同课色相拉开），亮色 / 深色主题各一套 tonal 配色
- **自建课程**：学校课表在下、自己加的课叠在上，两者分开存（学校刷新不会覆盖你的课）。长按空白格子新增，可填课名、教室、教师、星期、起止节次、周次（全部 / 单周 / 双周 / 逐周勾选）；自建课带描边与「自建 ·」前缀，点它可再次编辑或删除
- **冲突提醒**：同一天里节次重叠的不同课程会套一圈主题色，点一下翻卡查看另一门，长按看详情。首尾相接不算冲突
- **第 12 节**（21:45–22:30）已支持，网格、小组件、导出、提醒全线生效
- 自定义课表背景（纯色 / 渐变 / 图片）
- 导出：`.ics`（可导入系统日历）、`.csv`（可用 Excel 打开）、纯文本分享；**自建课程一并导出**，并在描述里标注来源
- 上课提醒：每节课开始前推一条通知（提前量 0/5/10/15/20/30 分钟，默认 15），展示课程名、教室与节次时间；同一时刻有多门课会汇总在一条通知里逐行列出；纯本地计算，不联网，换课表或关开关立刻生效；寒暑假不会响

### 成绩

- 按学期切换，统计加权平均分、总学分、课程数
- 与课表共用同一套 miniapp 会话，不重复握手

### 工作圈

- 动态时间线：浏览、点赞、评论、发表（含图片选择与上传）、九宫格图片、应用内图片预览（捏合缩放 / 双击放大 / 多图滑动）
- 个人资料页、我的动态（按年分组）
- **互动消息中心**：别人赞了 / 评论了你的动态，或者回复了你的评论，都会列在顶栏铃铛里，评论和赞分开显示，支持筛选、未读点、一键已读、点击进动态详情
- **只提醒与你有关的互动**：官方服务端会把你赞过的别人的动态的后续互动也推给你（实测一页 20 条里 15 条是这种噪音），本客户端只保留「动态作者是我」和「回复我的评论」两类
- **关键词搜索**：顶栏放大镜进入独立搜索页，翻时间线做本地匹配（服务端没有搜索接口），正文命中高亮、多词按「全部出现」收窄，可搜作者名；默认扫最近 300 条，不够就点「继续往前找」
- **关键词过滤**：设置 → 工具 → 工作圈过滤，四档预设（默认只开「广告推广」）+ 自定义词，命中就隐藏，时间线顶部不留任何过滤提示；被挡内容统一在「工作圈过滤 → 查看过滤消息」里看，每条标明命中的规则；找东西 / 还东西的帖子自动豁免，自己发的永不过滤

### 网上办事大厅

- 原生宫格 + 分类 + 搜索，不套官方那个必须注入 `loginCode / loginCookie / language` 才能正常显示的 H5 工作台
- 点卡片时才取**一次性** Token 再进 WebView，不会把长期凭证留在页面里

### 成员录

- 组织架构浏览：按部门树逐级下钻，每层显示下属单位与直属成员，带头像、职务与人数
- 找人：关键词搜索姓名 / 工号 / 手机号，命中结果可直接进个人主页
- 纯只读的组织名册，**没有**好友、私聊、收藏这类概念；组织树缓存 12 小时、部门成员缓存 6 小时，搜索不走缓存

### 图书馆座位

- 座位图选座（空闲 / 占用 / 我选的座位）、按开始时间与时长筛选可约时段
- 我的预约、签到码页面（馆内签到器扫的那条链路）
- 预约规则、逾期违约提示照服务端返回的规则展示

### 校园网（深澜 Srun）

- 状态卡（已认证 / 未认证 / 无法连接）+ 一键认证 / 下线（下线二次确认）
- 账号支持「学号 + 身份域」（学生 / 教职工 / 其他），身份域从门户登录页解析，不写死
- 密码用 **Android Keystore AES-GCM** 加密后存储，落盘的只有 `base64(iv):base64(ct)`
- 认证只在前台手动触发 —— **不做**打开 App 自动认证、**不做**后台保活
- 判断是否在校园网用门户探针，不读 SSID（因此不需要定位权限）

### 身份码

- 动态身份码二维码 + 条形码，点二维码可刷新，每次内容都会变，页面提示「请勿截图外传」

### 桌面小组件

| 小组件 | 内容 |
|---|---|
| 全周网格 | 整周课程按天与节次排布，点一下打开课表。**行列按当周实际课程自适应**：整周最晚只到第 8 节就不画 9–12 节，周六周日没课就不画这两列，省下的空间全部变成行高与列宽 |
| 今日课程 | 用课程卡片显示当天的课，可翻到前一天 / 后一天 |
| 校园网认证 | 显示认证状态与在线时长，点一下认证；已认证时点「下线」跳 App 确认 |

### 外观

- 主题：亮色 / 深色 / 跟随系统
- 语言：跟随系统 / 简体中文 / English（应用内切换，不依赖系统语言）
- 液态玻璃风格底栏与发表按钮（Compose 实现，仅限这两处）

### 入口速查

底栏四个 Tab：**课表 / 成绩 / 工作圈 / 设置**。剩下的功能都收在「设置」里：

| 想去哪 | 位置 |
|---|---|
| 网上办事大厅 | 设置 → 网上办事大厅 |
| 成员录（组织架构 / 找人） | 设置 → 成员录 |
| 外观（主题 / 课表背景 / 语言） | 设置 → 外观 |
| 上课提醒（含权限自检） | 设置 → 工具 → 上课提醒 |
| 课表导出（`.ics` / `.csv` / 文本） | 设置 → 工具 → 导出课表 |
| 工作圈关键词过滤 | 设置 → 工具 → 工作圈过滤 |
| 身份码 / 图书馆座位 / 校园网认证 | 设置 → 工具 |
| 当前账号、诊断日志、退出登录 | 设置首页 |
| 版本信息、反馈问题、源码链接、许可证 | 设置 → 关于 |

> 工作圈里还有三个只在**工作圈 Tab** 出现的顶栏入口：放大镜（关键词搜索）、铃铛（互动消息）、动态图标（我的动态）。

## 下载

到 [Releases](https://github.com/Micheal-Reber/lanhang-lite/releases) 下载最新版本页里的 `app-release.apk` 侧载安装。

- 需要 **Android 8.0（API 26）** 及以上
- 每个版本都用同一份 release 证书签名，可以直接覆盖安装升级，不用先卸载
- 首次启动需要学号 + 密码登录（与官方 App 同一套账号）
- 这里发布的 APK 是完整包，不受「仓库不含网络层」影响

## 构建

环境：

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Gradle | 8.14.3（**仓库未带 Wrapper**，用本机 Gradle 8.x 或自行 `gradle wrapper`） |
| AGP / Kotlin | 8.13.2 / 2.3.21 |
| compileSdk / targetSdk / minSdk | 36 / 35 / 26 |

### 先决条件：闭源模块（`engine`）

**克隆本仓库后不能直接构建**，会提示「缺少闭源网络层模块」。学校侧的接口地址、校园网认证协议实现、会话存储与 RSA 公钥都在未公开的 `:engine` 模块里，公开仓只包含业务编排、数据模型与界面。

这是刻意的：如果为了「clone 即编译」把这些放回来，公开就没有意义了。

| 你想做什么 | 需要什么 |
|---|---|
| 阅读实现、提 Issue、了解设计 | 不需要构建，源码可读 |
| 用现成版本 | 直接下载 [Releases](https://github.com/Micheal-Reber/lanhang-lite/releases) 的 APK |
| 自己构建 | 需要 `engine/`（私有开发环境）或 `app/libs/engine.aar`（预编译产物） |

`engine` 里的类**刻意保持原包名**（`com.lanhang.lite.net` / `oa` / `moments` / `session` 等），所以 `proguard-rules.pro` 里按包名的 keep 规则对 aar 同样生效，调用方代码也完全无感。

### 构建命令

```bash
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

依赖解析走阿里云镜像（见 `settings.gradle.kts`），国内网络下不用额外配置代理。

### Release 签名

release 构建需要四个签名参数，**写在 `~/.gradle/gradle.properties`，不要提交进仓库**：

```properties
lanhangReleaseStoreFile=/path/to/release.jks
lanhangReleaseStorePassword=***
lanhangReleaseKeyAlias=***
lanhangReleaseKeyPassword=***
```

四个参数缺任意一个时，构建**不会报错**，只是不会带上你的证书（产物是未签名包），所以打正式包后先确认一下：

```bash
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

> 打包注意：模型类靠 Gson 反射解析，`app/proguard-rules.pro` 里按**包名**写了 `-keep`。新增「用 Gson 解析」的包时必须同步加一行 `-keep class <包>.**`，否则 release 包会出现「登录失败 / 数据异常」而 debug 不复现。

## 数据来源

客户端直连校方 App 使用的接口，**没有自建服务端、没有中转服务器**，所有数据都从学校系统直接取。

接口地址、参数与字段细节不随仓库公开：这部分实现位于闭源 `engine` 模块（见上文）。公开仓里保留的是**调用编排**——哪个页面在什么时候要什么数据、怎么缓存、失败怎么提示——想了解这一层直接读各功能包下的 Repository。

图书馆座位与校园网认证的接口**只在校园网内可达**，校外要先连学校 VPN，否则对应页面会提示无法连接。

## 数据与隐私

- 登录会话（Cookie）、课表与成绩缓存、自建课程、设置项**全部只存在本机**（`SharedPreferences` + `filesDir`），不上传任何第三方服务器
- 校园网密码经 Keystore 加密后落盘，明文只存在于内存
- 诊断日志（`diagnostics.log`）写盘前对 cookie / token / 密码做脱敏，不含凭证原文
- 没有统计、埋点、崩溃上报，没有第三方 SDK 收集行为数据
- 唯一的对外网络请求就是上面这几套学校接口

## 已知限制

- **通知权限是提醒类功能的前置条件**：没有通知权限时，上课提醒的开关**打不开**——点开启会直接把你送去授权（系统权限框，或说明原因后跳设置页），授权回来才真正打开。这是刻意的：留一个「开着但永远不会响」的开关，只会让人以为搞定了。工作圈互动消息页同理，顶部提示条就是入口。
- **上课提醒要看精确闹钟权限**：Android 14 起，新装应用默认拿不到 `SCHEDULE_EXACT_ALARM`。不授权时闹钟的投递窗口实测可达一小时，晚于上课时刻的提醒会被**跳过而不是补发**（课都开始了，提醒只会打扰）。「设置 → 工具 → 上课提醒」把这件事摊开成页面顶部的一排状态（通知权限 / 精确闹钟 / 电池优化），缺哪项点哪项，能弹系统框就弹、弹不了就说明原因再跳设置页。
- **不是推送**：工作圈的互动提醒是每 15 分钟一次的本地轮询（`AlarmManager` 非精确闹钟）。App 被冻结、强制停止或深度省电时会延迟甚至没有提醒。真推送需要厂商通道或常驻长连接，本项目都没有。
- **已读只存本地**：服务端有「未读」概念但没有可验证的「标记已读」接口，猜错会把消息从历史里抹掉，所以没做。换设备后已读状态不同步。
- **消息比官方少**：过滤掉了「我赞过的别人的动态」上的互动，这是刻意差异，见上文。
- **搜索有深度上限**：服务端没有搜索接口，只能在客户端翻时间线本地匹配。默认扫最近 300 条（按实测日均约 114 条算，约 2~3 天），要更早的内容得点「继续往前找」，硬上限 1500 条；搜的是正文和作者名，不搜评论、不搜图片里的文字。
- **过滤是按词匹配，会误伤**：内置词表来自真实样本统计，仍可能挡掉个别正常内容（例如求购帖里留了微信号）。被挡的内容可在「设置 → 工具 → 工作圈过滤 → 查看过滤消息」里逐条核对（该页只能翻最近约 200 条的窗口，可点「继续往前找」往前扩，硬上限 1000 条）；找东西 / 还东西的帖子一律豁免。
- **自建课程只在本机**：没有云端同步，换设备、卸载重装或清除应用数据后就没了（学校课表能重新拉回来，自建的不能）。跨学期按学期隔离，旧学期的自建课不会串到新学期，也不会自动删除。
- **部分图片走校内地址**：头像等资源挂在校园网内的图床（明文 http），校外网络下可能加载不出来，会显示占位图；连校园网或 VPN 后正常。
- **只适配本校**：接口、字段、节次时间表都是南航的，换学校用不了。
- **接口随时可能变**：学校侧改版会导致某个功能失效，本项目不保证及时跟进。

## 项目结构

```
app/src/main/java/com/lanhang/lite/
  schedule/     课表取数与缓存、周次推算、作息时间表（全 App 唯一来源）、网格与列表两种
                渲染、自建课程、冲突反转、导出、背景、上课提醒调度
  grades/       学期列表与成绩缓存
  moments/      工作圈时间线、个人资料、互动消息、通知与未读的界面与状态
  oa/           办事大厅宫格界面与 WebView 承载
  library/      图书馆座位图、预约列表、签到码界面
  campusnet/    校园网认证界面与开关联动
  idcard/       动态身份码
  widget/       三个桌面小组件的数据快照与渲染
  core/         错误模型、加载状态、语言包装等公共件
  ui/           登录、主界面、主题、液态玻璃底栏
  settings/     设置、导出、诊断
```

```
engine/         （不在本仓库）接口地址与请求编排、校园网认证协议实现、
                会话持久化、RSA 公钥
```

> 各模块的约束与调研笔记不随源码公开，相关说明写在代码注释里。界面层与网络层的分工是：公开仓决定「什么时候要什么数据、怎么缓存、失败怎么提示」，`engine` 只负责「怎么拿到」。

## 参与

- 发现 bug 或有建议：[GitHub Issues](https://github.com/Micheal-Reber/lanhang-lite/issues)
- 提交代码前建议先读对应模块的注释，其中有不可破坏的约束（比如课表时间表只能有一份、模型包必须登记 R8 keep）
- 改界面文案要同时改 `values/strings.xml` 与 `values-en/strings.xml`，两个文件的键必须一致
- 改动涉及网络层（接口请求、认证、会话）的部分不在公开仓，这类 PR 只能描述现象与期望行为，实现由维护者在 `engine` 侧完成
