[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/Micheal-Reber/lanhang-lite)](https://github.com/Micheal-Reber/lanhang-lite/releases)
[![Android](https://img.shields.io/badge/Android-8.0%2B-green)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.3.21-purple)](https://kotlinlang.org)

南昌航空大学「蓝航」App 的第三方客户端，纯原生 Android（Kotlin + Material 3）。分两个包，可同时安装：

| | 包名 | 内容 | 体积 |
|---|---|---|---|
| **轻量版** | `com.lanhang.lite` | 课表 / 成绩 / 工作圈 / 办事大厅 / 图书馆 / 校园网 / 身份码，不含聊天 | 3.4 MB |
| **私信版** | `com.lanhang.lite.im` | 上面全部 + 私信（好友、群聊、语音、文件、位置、已读） | 5.3 MB |

官方 App 里大部分页面是联网加载的 H5，每次打开都要转圈。这个项目把每天真正会看的那几件事做成本地原生界面：能用缓存就不联网，能一次点完就不点三次。

> **本仓库不含网络层。** 学校侧接口地址、校园网认证协议实现与会话/密钥位于未公开的 `:engine` 模块，**克隆后无法直接构建**（这是刻意的）。只读代码不受影响，想跑起来请见 [先决条件：闭源模块](#先决条件闭源模块engine)。

## 和官方 App 的差别

| | 官方 App | 蓝航 Lite |
|---|---|---|
| 页面形态 | 多数功能是 H5，进入即转圈 | 课表、成绩、工作圈、宫格、图书馆、校园网全部原生渲染，先出缓存再联网 |
| 课表 | 只能看，不能改 | 支持**自建课程**（长按空白格添加，与学校课表分开存）、**冲突高亮**、**导出 `.ics` / `.csv`**、自定义背景、桌面小组件 |
| 课程提醒 | — | 每节课前提醒（提前量 0–30 分钟可选），纯本地计算，换课表立刻生效 |
| 工作圈 | 时间线 + 点赞评论 | 额外提供**关键词搜索**、**关键词过滤**、**按人屏蔽**、互动消息只保留与你有关的、离线快照、双击回顶 |
| 办事大厅 | 需要注入登录态的 H5 工作台 | 原生宫格 + 分类 + 搜索，点卡片时才取一次性 Token；断网显示 30 天内快照 |
| 校园网认证 | 在 App 内 | 状态卡 + 一键认证/下线，密码经 **Android Keystore AES-GCM** 加密落盘，不自动认证、不后台保活 |
| 私信 | 融云 IM 全套 | 会话、好友、群聊、语音、文件、位置、已读回执、聊天记录搜索，**不弹广告、不做埋点** |
| 主题 | 跟随系统 | 亮色 / 深色 / 跟随系统，可单独切中文 / English（不依赖系统语言） |
| 体积 | 完整功能包 | 3.4 MB / 5.3 MB 两个包，按需安装 |
| 网络诊断 | — | 登录失败时自动逐项探测 DNS / 主接口 / 课表服务，直接告诉你「卡在哪、该换什么网」 |
| 权限控制 | — | 可分别设置谁能看你的头像 / 手机号 / 邮箱 / 身份码，谁能加你好友、拉你进群、给你发消息 |

> 「—」表示官方 App 当前没有对应功能（截至 2026-11）。

## 功能

### 课表（底栏第一项）

- **两种视图**：网格（七列 × 12 节，含午休/晚休色带）与列表（整周摘要 + 每天课程），右上角一键切换
- **左右滑动翻周**：页面跟手平移，按「拖过距离 + 手速」判定吸附，首末周有阻尼回弹，换周保持纵向位置
- 今天整列铺淡蓝底；周次可点开选任意周
- **按周缓存**：进页面先显示缓存、不联网，下拉刷新才覆盖；切到没缓存的周才补拉
- 课程配色按课名哈希生成，亮/暗主题各一套
- **自建课程**：学校课表在下、自己的课叠在上，分开存储（学校刷新不会覆盖）；长按空白格新增，可设课名、教室、教师、星期、节次、周次（全部/单周/双周/逐周）
- **冲突提醒**：同一天节次重叠的课套主题色，点一下翻卡查看另一门
- 第 12 节（21:45–22:30）全线支持；自定义课表背景（纯色/渐变/图片）
- **导出**：`.ics`（导入系统日历）、`.csv`（Excel 打开）、纯文本分享，自建课程一并导出
- **上课提醒**：每节课前推一条通知，同一时刻多门课汇总成一条；寒暑假不响

### 工作（底栏第二项）

- 原生宫格 + 分类 + 搜索，不套官方那个必须注入 `loginCode / loginCookie` 才能显示的 H5 工作台
- **常用功能**：长按任意应用移入/移出，默认放校园网、图书馆座位、赣青二课
- 点卡片时才取**一次性** Token 再进 WebView，不把长期凭证留在页面里
- 断网显示上次的宫格快照（30 天），不会一片「加载失败」
- 内置入口：校园网、图书馆座位、赣青二课（江西省第二课堂平台，支持扫码签到）、校园卡支付

### 工作圈（底栏第三项）

- 时间线：浏览、点赞、评论、发表（图片上传）、九宫格、应用内图片预览（捏合/双击/多图滑动）
- 个人主页、我的动态（按年分组）
- **互动消息中心**：赞和评论分开显示，支持筛选、未读点、一键已读
- **只提醒与你有关的互动**：服务端会把「你赞过的别人的动态」上的后续互动也推给你（实测一页 20 条里 15 条是噪音），这里只保留「动态作者是我」和「回复我的评论」
- **关键词搜索**：翻时间线本地匹配，命中高亮，多词按「全部出现」收窄，可搜作者名
- **关键词过滤**：四档预设 + 自定义词，命中即隐藏；被挡内容统一在「查看过滤消息」里核对；失物招领类帖子自动豁免
- **不看某个人的动态**：对方动态、评论、点赞全部不出现；与关键词过滤分开判定，不受其总开关影响；名单有本地备份，不会因为更新丢失
- **双击回到顶部**；**离线快照**（10 条，7 天有效）

### 私信（仅私信版，底栏无独立 Tab，入口在设置）

- 会话列表、聊天页，消息类型：**文字 / 图片 / 视频 / 语音 / 文件 / 位置**
- **语音**：输入条左侧麦克风 → 「按住 说话」，上滑取消、松手发送，气泡点一下即播
- **好友**：个人主页加好友（验证语自动填本人姓名）、删除好友、新朋友列表、好友申请独立通知
- **群聊**：发起群聊（选好友、自动群名）、加入群聊（群号）、群会话
- **已读回执**（单聊）、**聊天详情页**（文件 / 图片 / 搜索、免打扰、置顶、清除记录）
- **聊天记录搜索**：结果按类型区分图标，点一条直接跳到那条消息并高亮
- **后台保活**：切后台也能收消息（可在设置 → 通用开关）；被系统限制联网时有提示

### 设置（底栏第四项）

- 账号信息、外观（主题 / 课表背景 / 语言）、通用（后台接收消息等）、工具、权限控制、关于
- **成绩**：按学期切换，统计加权平均分、总学分、课程数（1.0.0 起从底栏移到设置）
- **权限控制**：分别设置谁能看你的头像 / 手机号 / 邮箱 / 身份码，谁能加你好友、拉你进群、给你发消息
- **成员录**：组织架构浏览、按姓名/工号/手机号搜索
- 诊断日志、清除缓存（可选自动清理周期，默认 30 天）、检查更新（校验 SHA-256 后安装）

### 其他

- **图书馆座位**：座位图选座、我的预约、签到码（出码后每 2 秒自动轮询签到结果）
- **校园网（深澜 Srun）**：状态卡 + 一键认证/下线；账号支持「学号 + 身份域」，域从门户解析；密码 Keystore 加密
- **身份码**：动态二维码 + 条形码，每次内容都会变
- **桌面小组件**：全周网格（行列按当周课程自适应）、今日课程（可前后翻）、校园网认证（显示在线时长）

## 构建

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Gradle | 8.14.3（**仓库未带 Wrapper**） |
| AGP / Kotlin | 8.13.2 / 2.3.21 |
| compileSdk / targetSdk / minSdk | 36 / 35 / 26 |

### 先决条件：闭源模块（`engine`）

**克隆本仓库后不能直接构建**，会提示缺少闭源网络层模块。学校侧接口地址、校园网认证协议实现、会话存储与 RSA 公钥都在未公开的 `:engine` 模块里，公开仓只包含业务编排、数据模型与界面。

| 你想做什么 | 需要什么 |
|---|---|
| 阅读实现、提 Issue | 不需要构建，源码可读 |
| 用现成版本 | 直接下载 Releases 的 APK |
| 自己构建 | 需要 `engine/`（私有开发环境）或 `app/libs/engine.aar`（预编译产物） |

`engine` 里的类**刻意保持原包名**（`com.lanhang.lite.net` / `oa` / `moments` / `session` 等），所以 `proguard-rules.pro` 里按包名的 keep 规则对 aar 同样生效。

### 构建命令

```bash
gradle :app:assembleDebug          # 两个 flavor 的 debug 包
gradle :app:assembleRelease        # 两个 flavor 的 release 包
```

产物在 `app/build/outputs/apk/<flavor>/<buildType>/`。依赖解析走阿里云镜像（见 `settings.gradle.kts`）。

### Release 签名

release 构建需要四个参数，**写在 `~/.gradle/gradle.properties`，不要提交进仓库**：

```properties
lanhangReleaseStoreFile=/path/to/release.jks
lanhangReleaseStorePassword=***
lanhangReleaseKeyAlias=***
lanhangReleaseKeyPassword=***
```

四个参数缺任意一个时构建**不会报错**，只是不带证书（产物未签名），打完包先确认：

```bash
apksigner verify --print-certs app/build/outputs/apk/im/release/app-im-release.apk
```

> 打包注意：模型类靠 Gson 反射解析，`app/proguard-rules.pro` 里按**包名**写了 `-keep`。新增「用 Gson 解析」的包时必须同步加 `-keep class <包>.**`，否则 release 包会出现「登录失败 / 数据异常」而 debug 不复现。

## 数据来源

客户端直连校方 App 使用的接口，**没有自建服务端、没有中转服务器**。

接口地址、参数与字段细节不随仓库公开（在闭源 `engine`）。公开仓保留的是**调用编排**：哪个页面什么时候要什么数据、怎么缓存、失败怎么提示。

图书馆座位与校园网认证的接口**只在校园网内可达**，校外要先连学校 VPN。

## 数据与隐私

- 登录会话、课表与成绩缓存、自建课程、设置项**全部只存在本机**，不上传任何第三方服务器
- 校园网密码经 Keystore 加密后落盘，明文只在内存
- 诊断日志写盘前对 cookie / token / 密码脱敏
- **没有统计、没有埋点、没有崩溃上报、没有第三方广告 SDK**
- 唯一的对外请求就是上面这几套学校接口
- 图片缓存上限 150MB（Coil LRU 淘汰）；课表、成绩、自建课程、离线快照不在清理范围内

## 已知限制

- **通知权限是提醒类功能的前置条件**：没有通知权限时上课提醒的开关打不开，点开启会直接引导授权。留一个「开着但永远不会响」的开关只会让人以为搞定了。
- **上课提醒要看精确闹钟权限**：Android 14 起新装应用默认没有 `SCHEDULE_EXACT_ALARM`，不授权时闹钟投递窗口可达一小时，晚于上课时刻的提醒会被跳过而不是补发。「设置 → 工具 → 上课提醒」把权限状态摊开成页面顶部一排，缺哪项点哪项。
- **厂商的省电策略管不了**：App 被冻结时，闹钟和通知都会被延迟（实测有 6 分钟才投递的）。
- **不是推送**：工作圈的互动提醒是 15 分钟一次的本地轮询（非精确闹钟），进程被冻结/强停会延迟甚至没有。
- **搜索有深度上限**：服务端没有搜索接口，只能本地翻时间线。默认扫最近 300 条，硬上限 1500 条；不搜评论、不搜图片里的文字。
- **过滤是按词匹配，会误伤**：被挡内容可在「查看过滤消息」里逐条核对；找东西/还东西的帖子一律豁免。
- **自建课程只在本机**：换设备、卸载重装或清除数据后就没了（学校课表能重新拉，自建的不能）。
- **部分图片走校内地址**：头像挂在校园网内的图床（明文 http），校外可能加载不出来，连校园网或 VPN 后正常。
- **只适配本校**：接口、字段、节次时间表都是南航的。
- **移动数据下可能连不上**：部分运营商到教育网的链路不通，或对明文 HTTP 劫持；登录页的「网络诊断」能测出卡在哪一段。课表服务只能走明文 HTTP，这是服务端限制。
- **接口随时可能变**：学校侧改版会导致某个功能失效，不保证及时跟进。

## 项目结构

```
app/src/main/java/com/lanhang/lite/
  schedule/     课表取数与缓存、周次推算、作息时间表（全 App 唯一来源）、两种渲染、
                自建课程、冲突反转、导出、背景、上课提醒调度
  grades/       学期列表与成绩缓存
  moments/      工作圈时间线、个人资料、互动消息、过滤与屏蔽、通知
  oa/           办事大厅宫格、本地入口（校园网 / 图书馆 / 二课）、WebView 承载
  library/      图书馆座位图、预约列表、签到码
  campusnet/    校园网认证界面与开关联动
  idcard/       动态身份码
  widget/       三个桌面小组件的快照与渲染
  core/         错误模型、加载状态、语言包装、文件打开等公共件
  ui/           登录、主界面、主题、液态玻璃底栏
  settings/     设置、导出、诊断、权限控制
app/src/im/     （仅私信版）会话、聊天、好友、群聊、语音、文件、通知
engine/         （不在本仓库）接口地址与请求编排、校园网认证协议、会话持久化、RSA 公钥
```
